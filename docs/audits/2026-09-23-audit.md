## ⚠ Déploiement — rupture de protocole

Le format signé change : **serveur et firmware doivent être mis à jour
ensemble**. Une box en ancien firmware reçoit 401 sur `/api/box/auth` dès que
le serveur est déployé (et inversement).

Procédure pour la box de test `ESP32S3-8FF7-D684` :

1. Déployer le web (Coolify, push sur `master`).
2. Brancher la box, **flash complet** (la table de partitions change) — la
   commande du CLAUDE.md écrit bootloader + table + otadata + app, sans toucher
   la NVS applicative (0x9000) :
   ```
   cd firmware && python -m esptool --chip esp32s3 -p /dev/ttyACM0 -b 460800 \
     --before default-reset --after hard-reset write_flash --flash_mode dio \
     --flash_size 16MB --flash_freq 80m 0x0 build/bootloader/bootloader.bin \
     0x8000 build/partition_table/partition-table.bin \
     0xf000 build/ota_data_initial.bin 0x20000 build/blackbox.bin
   ```
3. Logs attendus au premier boot :
   `box_auth: box provisionnée: ESP32S3-8FF7-D684 (identité migrée vers box_nvs)`,
   puis `cloud_client: authentifiée auprès de https://box.agill.es`.
   Au boot suivant : `box provisionnée: ESP32S3-8FF7-D684` (lu depuis box_nvs).
4. Si la migration échoue : `BOX_MASTER_SECRET=<hex> python3 tools/provision_box.py --flash`
   (n'écrit que `box_nvs`).

## Points restants (non traités)

### 🟠 Moyen
6. **Schéma DB absent du dépôt** — pas de migrations ni de policies RLS
   versionnées ; non vérifiable : `UNIQUE(devices.box_uid)` (race sur
   `/register` concurrent), policy insert `waitlist`, index `box_challenges`.
   → `supabase/migrations/` (DDL à passer par Gilles dans Studio).
7. **Version de scénario en double** — `scenarios.version` (DB) et
   `manifest.json` doivent coïncider à la main ; si divergence,
   `cloud_client.c` re-télécharge le manifest et re-hashe tous les fichiers à
   chaque sync. → le serveur lit la version dans le manifest.
8. **Clé JWT = master brut** (`box-auth.ts`, commentaire « dérivée » faux) —
   réutilisation de clé HKDF/HMAC. → `HKDF(master, "escapebox:jwt")` + `iss`/`aud`.
9. **Pas de rate limiting** sur `/api/box/*` — `/challenge` non authentifié
   insère une ligne par appel.
10. **WiFi sans reconnexion** après 5 échecs (`hal_wifi.c`) et **pas de sync
    périodique** (boot / appairage uniquement).
11. **BLE sans LE Secure Connections** (`sm_sc = 0`) — mot de passe WiFi en
    clair dans les airs ; fenêtre BLE non fermée après `wifi_ok`.
12. **Secure Boot / flash encryption désactivés**, secret en clair en NVS —
    acceptable en proto, pas en production. Packages en clair sur la SD
    (copie triviale) : choix business.
13. **`shadcn` en `dependencies`** → tire `@modelcontextprotocol/sdk`, express,
    hono, body-parser : vulnérabilités `high` à `npm audit`. → devDependencies
    + `npm audit fix`.
