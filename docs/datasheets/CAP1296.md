# CAP1296 (Microchip) — contrôleur tactile 6 canaux, SMBus/I2C

> _Synthèse de la datasheet DS00001569B (fichier local [./CAP1296.pdf](./CAP1296.pdf) — PDF
> chiffré AES-128 sans mot de passe d'ouverture), lue le 2026-09-27._

**Catégorie** : 6 entrées tactiles, détection de proximité, garde active (SG, broche 12)
**LCSC / JLCPCB (27/09/2026)** : CAP1296-1-SL (SOIC-14) C1522283, 1,24 $, stock 9 ;
CAP1296-1-AIA-TR (DFN-10 3 × 3) C2652051, 1,78 $, stock 127

## Point bloquant pour le projet

- **Adresse SMBus fixe `0101_000` = 0x28** (§3.2.2, « The CAP1296 responds to SMBus address
  0101_000 »). **Deux CAP1296 ne peuvent pas cohabiter sur le même bus** sans multiplexeur I2C
  ou traducteur d'adresse. Écarté le 2026-09-27 pour le clavier 12 touches de Côté 2.

## Autres points vérifiés

- **6 entrées CS1-CS6** ; **CS3 partagée avec SG** (garde active) → 5 touches si la garde est
  utilisée (tableau 1-1).
- VDD **3,0 à 5,5 V** (caractéristiques électriques).
- **ALERT#** active basse, drain ouvert, pull-up requis.

## Notes projet

- Reste une option à **un seul exemplaire** (6 canaux + proximité + garde), par exemple pour
  « approche ta main » sur Côté 3.
