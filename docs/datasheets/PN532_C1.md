# PN532 (fiche courte C1)

> ⚠️ **Composant abandonné, remplacé par le ST25DV04KC** (tag NFC dynamique, voir
> [./ST25DV04K.md](./ST25DV04K.md)). Conservé pour l'historique ; le driver `hal_nfc`
> PN532 est obsolète (FSD §3.1).
>
> _Synthèse de la fiche courte NXP PN532 C1 (fichier local [./PN532_C1.pdf](./PN532_C1.pdf))._

**Fabricant** : NXP Semiconductors
**Catégorie** : Contrôleur NFC 13,56 MHz (lecteur/écriveur, émulation de carte, NFCIP-1) avec cœur 80C51
**Référence officielle** : PN532

## Vue d'ensemble

Module de transmission sans contact 13,56 MHz : lecteur/écriveur ISO 14443A/MIFARE,
FeliCa et ISO 14443B, mode carte ISO 14443A/FeliCa, mode NFCIP-1. Pilote une antenne
lecteur sans circuit actif additionnel. La fiche C1 est une version courte : se référer à
la datasheet produit complète pour le détail.

## Pourquoi il a été remplacé

La box n'a plus besoin de lire des badges : la seule interaction NFC retenue est
« le téléphone lit la box » (NDEF), assurée par un tag dynamique ST25DV, compatible iPhone
et sans la limitation HCE d'iOS (FSD R-11).
