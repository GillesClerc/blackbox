# TMAG5273

> _Synthèse de la datasheet TI SLYS045C (rév. avril 2026, fichier local [./TMAG5273.pdf](./TMAG5273.pdf))._

**Fabricant** : Texas Instruments
**Catégorie** : Capteur à effet Hall linéaire 3D, basse consommation, I2C
**Référence officielle** : TMAG5273**A1** (±40/80 mT, 0x35) — voir tableau des variantes
**Datasheet source** : https://www.ti.com/lit/ds/symlink/tmag5273.pdf

## Vue d'ensemble

Trois capteurs Hall (X, Y, Z) + ADC 12 bits, capteur de température, calcul d'angle
CORDIC, moyennage jusqu'à ×32, I2C 1 MHz avec CRC optionnel, broche INT (seuils ou
déclenchement de conversion), modes wake-up/sleep (1 µA) et deep sleep (5 nA).

## Variantes et adresses I2C (tableau 6-2)

| Version | Plage | Adresse 7 bits |
|---|---|---|
| **TMAG5273A1** / A2 | ±40/±80 mT (x1) / ±133/±266 mT (x2) | **0x35** |
| TMAG5273B1 / B2 | idem | 0x22 |
| TMAG5273C1 / C2 | idem | 0x78 |
| TMAG5273D1 / D2 | idem | 0x44 |

L'adresse d'usine est chargée depuis l'OTP ; elle peut être modifiée par le registre
I2C_ADDRESS après la mise sous tension (non persistant).

## Package & Footprint

- **Package** : SOT-23-6 (DBV)

## Pinout (tableau 4-1)

| Pin | Nom | Fonction |
|---|---|---|
| 1 | SCL | Horloge I2C |
| 2 | GND | Masse |
| 3 | GND (TEST) | Pin de test TI : **relier à GND** |
| 4 | VCC | Alimentation |
| 5 | INT | Interruption (E/S). Non utilisée et reliée à GND → mettre **MASK_INTB = 1b** |
| 6 | SDA | Données I2C |

## Notes spécifiques projet

- Satellite face Côté 3 (« approche ta main » / « pose un objet » avec aimant). Brochage de
  la netlist documentée **conforme** (SCL 1, GND 2, TEST 3 → GND, VCC 4, INT 5, SDA 6).
- L'adresse **0x35 du FSD impose de commander une variante A** : A1 (±40/80 mT) pour la
  sensibilité à un petit aimant à distance.
- INT : pas de GPIO libre côté Main → la laisser non connectée ou la relier à GND et
  mettre MASK_INTB = 1 dans le firmware.
