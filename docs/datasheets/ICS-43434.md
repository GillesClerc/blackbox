# ICS-43434

> _Synthèse de la datasheet TDK InvenSense DS-000069 v1.2 (fichier local [./ICS-43434.pdf](./ICS-43434.pdf), copie Farnell)._

**Fabricant** : TDK InvenSense
**Catégorie** : Microphone MEMS numérique, sortie I2S 24 bits
**Référence officielle** : ICS-43434 (LGA-6, port par le dessous)
**Datasheet source** : https://invensense.tdk.com/wp-content/uploads/2016/02/DS-000069-ICS-43434-v1.2.pdf

## Vue d'ensemble

Micro omnidirectionnel avec ADC sigma-delta, filtres de décimation et interface I2S
esclave (24 bits, complément à deux). Deux modes (haute performance / basse consommation)
selon la fréquence d'échantillonnage ; veille automatique si SCK < ~200 kHz.

## Package & Footprint

- **Package** : LGA-6 3,5 × 2,65 mm, port acoustique par le dessous (trou dans le PCB)
- **Empreinte KiCad** : `Sensor_Audio:InvenSense_ICS-43434-6_3.5x2.65mm` ; LCSC C5656610 (BOM projet)

## Interface

- I2S esclave, 24 bits, **64 cycles SCK par trame WS**.
- Canal gauche (LR bas) : données après le front descendant de WS.
- Ne pas envoyer d'horloges (WS/SCK) quand VDD est coupé (diodes ESD passantes, fiabilité).

## Notes spécifiques projet

- **U4** : VDD = 3V3_A ✓, LR = GND (gauche) ✓, SD avec R_SD_PD 100 kΩ ✓, I2S1 : SCK = GPIO16,
  WS = GPIO18, SD = GPIO7.
- ⚠ Pas de condensateur de 0,1 µF au pied de VDD (fortement recommandé par la datasheet,
  au plus près des pins 5/3, sans via) → à ajouter.
