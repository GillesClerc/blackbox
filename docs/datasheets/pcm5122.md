# PCM5122 (PCM5122PW)

> _Synthèse de la datasheet TI SLAS763C (fichier local [./pcm5122.pdf](./pcm5122.pdf)). Référence registres détaillée : [./pcm5122-registers.md](./pcm5122-registers.md)._

**Fabricant** : Texas Instruments
**Catégorie** : DAC audio stéréo 32 bits / 384 kHz, sortie ligne DirectPath 2,1 Vrms, PLL intégrée
**Référence officielle** : PCM5122PW (TSSOP-28)
**Datasheet source** : https://www.ti.com/lit/ds/symlink/pcm5122.pdf

## Vue d'ensemble

DAC I2S avec PLL (peut générer ses horloges depuis BCK, sans SCK/MCLK), charge pump
négative intégrée (sortie centrée sur la masse, pas de condensateurs de liaison en sortie),
DSP à filtres sélectionnables, contrôle par I2C, SPI ou broches (mode câblé).

## Package & Footprint

- **Package** : TSSOP-28, 4,4 × 9,7 mm, pas 0,65 mm
- **Empreinte LCSC** : C1540085 (BOM projet)

## Pinout (mode I2C — celui du projet)

| Pin | Nom | Fonction |
|---|---|---|
| 1 | CPVDD | Alimentation charge pump, **3,3 V obligatoire** |
| 2 | CAPP | Condensateur volant de la charge pump (borne +) |
| 3 | CPGND | Masse charge pump |
| 4 | CAPM | Condensateur volant de la charge pump (borne −) |
| 5 | VNEG | Rail négatif −3,3 V de la charge pump : **condensateur de découplage vers GND** |
| 6 / 7 | OUTL / OUTR | Sorties ligne gauche / droite |
| 8 | AVDD | Alimentation analogique, **3,3 V obligatoire** |
| 9 | AGND | Masse analogique |
| 10 | VCOM | Mode VREF (défaut) : **relier à GND**. Mode VCOM : découplage vers GND |
| 11 / 12 | SDA / SCL | Bus I2C |
| 13–15, 19 | GPIO5, GPIO4, GPIO3, GPIO6 | GPIO généraux, **pull-down interne** |
| 16 | ADR2 | Bit d'adresse I2C 2 |
| 17 | MODE1 | Sélection du mode de contrôle |
| 18 | MODE2 | Sélection du mode de contrôle |
| 20 | SCK | Horloge système (GND si PLL depuis BCK) |
| 21 | BCK | Horloge bit I2S |
| 22 | DIN | Données I2S |
| 23 | LRCK | Horloge mot I2S |
| 24 | ADR1 | Bit d'adresse I2C 1 |
| 25 | XSMT | Soft mute : bas = mute, haut = un-mute (peut être relié à AVDD) |
| 26 | LDOO | Sortie LDO interne 1,8 V : **découplage 0,1 µF** |
| 27 | DGND | Masse numérique |
| 28 | DVDD | Alimentation numérique / IO (1,8 V ou 3,3 V) |

**Mode de contrôle** : MODE1 = L & MODE2 = L → câblé ; **MODE1 = L & MODE2 = H → I2C** ;
MODE1 = H → SPI.
**Adresse I2C** : `1 0 0 1 1 ADR2 ADR1` → ADR1 = ADR2 = GND → **0x4C**.

## Séquence d'initialisation (mode I2C, PLL depuis BCK)

Voir `pcm5122-registers.md` et `firmware/components/hal_audio/hal_audio.c` (déjà implémentée) :
standby → PLL source BCK → P/J/D/R → diviseurs → format I2S → volume → sortie de standby.

## Layout (datasheet §11)

Découplages alimentation et charge pump au plus près du composant ; plan de masse commun
AGND/DGND ; horloges numériques éloignées des sorties analogiques ; ground pour séparer
OUTL/OUTR.

## Notes spécifiques projet

- **U2** : MODE1 = GND, MODE2 = 3V3_A (I2C) ✓, ADR1/ADR2 = GND (0x4C) ✓, SCK = GND ✓,
  VCOM = GND ✓, XSMT via 10 kΩ vers 3V3_A ✓, LDOO 100 nF ✓, GPIO3–6 flottantes ✓.
- ⚠ **C20** : câblé CAPM → VNEG ; la datasheet exige VNEG → GND (découplage du rail
  négatif). À corriger (audit 2026-09-23).
- Sortie 2,1 Vrms à 0 dB vers un PAM8406 à gain fixe 24 dB : limiter le volume numérique
  (voir `PAM8406.md`).
